Weather Checker

A responsive weather application built with React.js and Tailwind CSS that allows users to check real-time weather information for any city.

Features

Search weather by city name
Display current temperature
Show weather conditions
Display feels-like temperature
Show humidity and wind speed
Responsive user interface

Technologies Used

React.js
JavaScript
Tailwind CSS
Weather API
Vite
